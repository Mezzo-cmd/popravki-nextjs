# 📖 Подробно ръководство — Popravki.bg от нула до онлайн

---

## ═══════════════════════════════════
## СТЪПКА 1: Инсталирай Node.js
## ═══════════════════════════════════

1. Отиди на **https://nodejs.org**
2. Кликни голямото зелено копче **"LTS"** (напр. 20.x LTS)
3. Изтегли `.msi` файла и го инсталирай (Next, Next, Finish)
4. Провери: отвори **Command Prompt** (Win+R → cmd → Enter) и напиши:
   ```
   node --version
   ```
   Трябва да видиш нещо като `v20.11.0`

---

## ═══════════════════════════════════
## СТЪПКА 2: Отвори папката с проекта
## ═══════════════════════════════════

1. Отвори **File Explorer**
2. Отиди в `D:\CLAUDE\popravki-nextjs`
3. Кликни в адресната лента (горе) → напиши `cmd` → Enter
   _(Ще се отвори Command Prompt директно в тази папка)_

4. Напиши и натисни Enter:
   ```
   npm install
   ```
   Изчакай 1-2 минути. Ще видиш много текст — нормално е.

## ═══════════════════════════════════
## СТЪПКА 3: Създай Supabase проект
## ═══════════════════════════════════

### 3.1 Регистрация в Supabase (безплатно)
1. Отиди на **https://supabase.com**
2. Кликни **"Start your project"** (горе вдясно)
3. Кликни **"Continue with GitHub"** или **"Sign Up with Email"**
4. Потвърди имейла си

### 3.2 Създай нов проект
1. След влизане → кликни **"New project"**
2. Попълни:
   - **Name:** `popravki-bg`
   - **Database Password:** измисли си парола (напр. `Popravki2024!`) — **ЗАПОМНИ Я**
   - **Region:** избери **`EU Central (Frankfurt)`**
3. Кликни **"Create new project"**
4. **Изчакай 2-3 минути** докато се зарежда (ще видиш въртящ се кръг)

### 3.3 Изпълни базата данни
1. В лявото меню кликни **"SQL Editor"** (иконата изглежда като `</>`  )
2. Кликни **"New query"** (горе вляво)
3. Отвори файла `D:\CLAUDE\popravki-nextjs\supabase\schema.sql` с Notepad
4. **Ctrl+A** → **Ctrl+C** (копирай всичко)
5. Кликни в белия текстов прозорец в Supabase → **Ctrl+V** (постави)
6. Кликни зеления бутон **"Run"** (▶ горе вдясно) или натисни **Ctrl+Enter**
7. Трябва да видиш: **"Success. No rows returned"** (долу)

   ⚠️ Ако видиш грешка в червено — изпрати ми съобщението

### 3.4 Вземи API ключовете
1. В лявото меню кликни **"Settings"** (иконата е зъбно колело ⚙️, най-долу)
2. Кликни **"API"**
3. Ще видиш три неща — **копирай ги и ги запази в Notepad**:

   ```
   Project URL:
   https://НЕЩО.supabase.co
   
   anon public (под "Project API keys"):
   eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...  (дълъг ключ)
   
   service_role (под "Project API keys" — кликни "Reveal"):
   eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...  (друг дълъг ключ)
   ```

## ═══════════════════════════════════
## СТЪПКА 4: Конфигурирай проекта
## ═══════════════════════════════════

1. Отиди в `D:\CLAUDE\popravki-nextjs`
2. Намери файла **`.env.local.example`**

   > ⚠️ Ако не виждаш файла: в File Explorer → View → **Show hidden items** ✓

3. **Копирай** файла и го **преименувай** на **`.env.local`**
   (десен клик → Copy → постави в същата папка → преименувай)

4. Отвори `.env.local` с Notepad (десен клик → Open with → Notepad)

5. Замени стойностите с твоите от Supabase:
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://ТВОЕТО_НЕЩО.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...anon_key_тук...
   SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOi...service_role_тук...
   ADMIN_EMAILS=твоят_имейл@нещо.com
   ```

6. **Файл → Запази** (Ctrl+S)

4. Трябва да видиш сайта Popravki.bg!

   ✅ Ако виждаш сайта → продължи към Стъпка 6
   ❌ Ако има грешка → изпрати ми текста на грешката

## ═══════════════════════════════════
## СТЪПКА 6: Качи в GitHub
## ═══════════════════════════════════

### 6.1 Инсталирай Git (ако нямаш)
1. Отиди на **https://git-scm.com/download/win**
2. Изтегли и инсталирай (Next, Next, Finish)

### 6.2 Създай GitHub акаунт (ако нямаш)
1. Отиди на **https://github.com** → Sign Up

### 6.3 Качи проекта
В Command Prompt (в папката `popravki-nextjs`):

```bash
git init
git add .
git commit -m "Initial commit - Popravki.bg"
```

След това:
1. Отиди на **https://github.com/new**
2. **Repository name:** `popravki-bg`
3. Избери **Private** (препоръчително)
4. Кликни **"Create repository"**
5. GitHub ще ти покаже команди — копирай и изпълни тези две:
   ```bash
   git remote add origin https://github.com/ТВОЕТО_ИМЕ/popravki-bg.git
   git push -u origin main
   ```
   (ще поиска GitHub потребителско Иmе и парола)

## СТЪПКА 7: Deploy на Vercel
## ═══════════════════════════════════

### 7.1 Създай Vercel акаунт
1. Отиди на **https://vercel.com**
2. Кликни **"Sign Up"** → **"Continue with GitHub"**
3. Оторизирай Vercel да достъпи GitHub

### 7.2 Import проекта
1. В Vercel dashboard → кликни **"Add New..."** → **"Project"**
2. Намери `popravki-bg` в списъка → кликни **"Import"**
3. Vercel ще разпознае Next.js автоматично

### 7.3 Добави Environment Variables
Преди да кликнеш Deploy → разгъни **"Environment Variables"** секцията:

Добави тези един по един (Name → Value → Add):

| Name | Value |
|------|-------|
| `NEXT_PUBLIC_SUPABASE_URL` | `https://xxx.supabase.co` |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | `eyJ...твоят anon key...` |
| `SUPABASE_SERVICE_ROLE_KEY` | `eyJ...твоят service_role key...` |
| `ADMIN_EMAILS` | `твоят@имейл.com` |

### 7.4 Deploy!
1. Кликни **"Deploy"**
2. Изчакай 2-3 минути (ще видиш логове)
3. Когато завърши → ще видиш **"Congratulations!"** и линк като:
   `https://popravki-bg-нещо.vercel.app`

## СТЪПКА 8: Настрой Supabase за production
## ═══════════════════════════════════

1. В Supabase → **Authentication → URL Configuration**
2. **Site URL:** `https://твоят-домейн.vercel.app`
3. **Redirect URLs** → Add → `https://твоят-домейн.vercel.app/auth/callback`
4. Кликни **Save**

## ═══════════════════════════════════
## СТЪПКА 9: Направи се Admin
## ═══════════════════════════════════

1. Отиди на твоя сайт → кликни **Вход** → **Регистрирай се**
   (регистрирай се с имейла от `ADMIN_EMAILS`)

2. В Supabase → **Authentication → Users**
3. Намери твоя акаунт → копирай **UUID** (напр. `550e8400-e29b-41d4-a716...`)

4. В **SQL Editor** → New query → изпълни:
   ```sql
   UPDATE public.profiles
   SET role = 'admin'
   WHERE id = 'ПОСТАВИ_UUID_ТУК';
   ```
   Замени `ПОСТАВИ_UUID_ТУК` с твоя UUID.

5. Кликни **Run** → "Success"

6. Излез от сайта → Влез отново → Отиди на `/admin`
   Трябва да видиш Админ панела! 🎉

## 🆘 Помощ при грешки

**"npm : The term 'npm' is not recognized"**
→ Node.js не е инсталиран или трябва да рестартираш Command Prompt

**"Cannot find module"**
→ Изпълни `npm install` отново

**Сайтът се зарежда но няма майстори**
→ Провери дали `schema.sql` е изпълнен и demo данните са вмъкнати

**"Invalid API key"**
→ Провери `.env.local` — ключовете трябва да са без кавички и без интервали
